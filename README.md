# Adventure Quest: Pixel Kingdom

An original, offline 2D side-scrolling platformer for Android, designed for
portrait (9:16) play with thumb-friendly touch controls. Built with
**Godot 4.4** and GDScript. All characters, art, music, sound effects and
levels are original and generated by the scripts in `tools/`, so the project
has no paid or external asset dependencies.

* 8 themed worlds, 5 levels each (40 levels), every world ending in a boss
* Run, sprint, variable-height jump, stomp, swim, ride wind and platforms
* Coins, gems, hidden treasure stars, secret rooms, breakable/bonus/hidden blocks
* Six power-ups, three-star rating per level, checkpoints, lives and hearts
* Local save of progress, stars, best scores and settings
* No network permission and no internet needed

## Install the APK

A ready-built, signed release APK is in `dist/AdventureQuest-v1.0.0.apk`
(arm64-v8a + armeabi-v7a, Android 5.0 / API 21 and newer).

1. Copy the APK to your phone (or use `adb install dist/AdventureQuest-v1.0.0.apk`).
2. Open it and allow installing from this source when Android asks.

The included APK is signed with a throwaway key generated while building it.
It installs and runs normally, but to publish the game (for example on
Google Play) build and sign it with your own key as described below.

## Controls

| Touch (portrait) | Keyboard | Gamepad | Action |
|---|---|---|---|
| Bottom-left ◀ ▶ pads (slide between them) | ← → / A D | D-pad | Move |
| Bottom-right **JUMP** | Space / Z / ↑ / W | A | Jump (hold longer to jump higher). Swim stroke underwater |
| **RUN** above JUMP | Shift / X | X | Hold to sprint. With Energy Blast, tap to fire |
| **II** top-left | Esc / P | Start | Pause |
| Android back button | | | Pause / back |

Every finger is tracked separately, so moving, running and jumping work at
the same time. The controls can be resized in Settings.

## How to play

* **Health and lives.** You have 3 hearts per life and start with 5 lives.
  Enemies, spikes and projectiles cost a heart; pits and lava cost a life.
  100 coins, hidden blocks and Extra Life items give lives. Running out of
  lives only restarts the level; unlocked levels are never lost.
* **Enemies.** Land on top of most enemies to defeat them. Chain stomps
  without touching the ground for more points. Shellbacks hide in their shell
  when stomped; touch the shell to kick it into other enemies. Glimmershade
  ghosts freeze while you face them and can only be defeated with Energy Blast
  or a kicked shell.
* **Blocks.** Hit blocks from below: bricks break, gold blocks give coins or
  power-ups. Some blocks are invisible until you jump into them.
* **Checkpoints.** Touch a flag to make it your respawn point.
* **Secrets.** Each level hides 1 to 3 star treasures behind fake walls, on
  high ledges reached from hidden blocks, or inside bonus rooms behind purple
  portals.
* **Stars.** Each level awards up to three stars: collect 70% of the coins,
  find every secret star, and finish within the par time. Replay levels to
  earn missing stars and beat your best score.

## Project structure

```
project.godot            Godot project settings (portrait, GL Compatibility renderer)
export_presets.cfg       Android export preset (no Gradle build needed)
scenes/main.tscn         Boot scene (splash)
scripts/autoload/        Game (save, progression, flow, input map) and Audio singletons
scripts/game/            Gameplay: level builder, player, enemies, boss, blocks,
                         pickups, triggers, hazards, platforms, projectiles, HUD,
                         touch controls, level-file parser
scripts/ui/              Splash, main menu, world/level select, settings, credits,
                         victory and shared UI helpers
scripts/tests/           Automated in-engine test runner
levels/w<W>_<L>.txt      The 40 levels as plain-text data
assets/                  Generated sprites, tilesets, parallax backgrounds, audio
tools/gen_art.py         Generates all pixel art and the app icon
tools/gen_audio.py       Synthesizes all music loops and sound effects
tools/gen_levels.py      Builds the 40 level files from designed chunks
tools/validate_levels.py Physics-based check that every level can be completed
tools/build_android.sh   Command-line APK build
```

Gameplay code never hard-codes a level: `scripts/game/level.gd` reads a level
file and builds tiles, merged collision shapes and entities from it.

### Level format

A level file is a header of `key=value` lines, a `---` line, then 18 rows of
characters (one per 16 px tile). Header keys: `name`, `world`, `level`, `par`
(seconds for the time star), `music`, `powerups` (order handed out by power-up
blocks), `main_end` (column where the camera stops), `warp=x,y>x,y` (portal
from cell to cell), `room=x0,x1` (bonus room columns), `sign=text` (tutorial
signs in left-to-right order), `boss=kind`, `arena=x0,x1`, `dark=1`,
`underwater=1`.

| Char | Meaning | Char | Meaning |
|---|---|---|---|
| `#` | ground | `S` | player start |
| `X` | metal block | `F` | goal beacon |
| `I` | ice | `C` | checkpoint |
| `=` | one-way platform | `T` | tutorial sign |
| `c` | crumbling platform | `o` | coin |
| `B` | brick | `g` | gem |
| `?` | coin block | `*` | secret star |
| `U` | power-up block | `1`-`6` | speed, shield, mega, blast, magnet, life |
| `H` | hidden block (extra life) | `e r f h G y n m` | walker, roller, flyer, hopper, ghost, yeti, fish, magma enemies |
| `O` | fake wall (walk through) | `K` | boss |
| `^` | spikes | `M` / `V` | horizontal / vertical moving platform |
| `L` | lava | `R` | falling rock |
| `W` | water | `Y` | crusher |
| `<` `>` | water current | `z` | spike ball |
| `A` | air bubble vent | `j` | lava fireball jumper |
| `Q` | quicksand | `Z` | wind updraft |
| `d` `D` | decorations | `.` | empty |

Edit files by hand, or change `tools/gen_levels.py` and run it again
(it overwrites all 40 files). Run `tools/validate_levels.py` afterwards.

## Building

### Requirements

* Godot **4.4.1** (standard build) and its export templates
  (Editor > Manage Export Templates > Download, or the `.tpz` from the Godot
  releases page)
* JDK 17 or newer
* Android SDK with `platform-tools` and `build-tools` (Android Studio's SDK
  is fine). In Godot set Editor > Editor Settings > Export > Android >
  *Java SDK Path* and *Android SDK Path*, and point *Debug Keystore* at a
  debug keystore (Godot can generate one).

### Debug APK

```
tools/build_android.sh debug            # -> build/AdventureQuest-debug.apk
```

or in the editor: Project > Export > Android > Export Project.

### Signed release APK

1. Create your release key once and keep it safe; you need the same key for
   every future update:
   ```
   keytool -genkeypair -v -keystore my-release.keystore -alias adventurequest \
     -keyalg RSA -keysize 2048 -validity 10000
   ```
2. Build:
   ```
   export GODOT_ANDROID_KEYSTORE_RELEASE_PATH=$PWD/my-release.keystore
   export GODOT_ANDROID_KEYSTORE_RELEASE_USER=adventurequest
   export GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD='your password'
   tools/build_android.sh release      # -> build/AdventureQuest-release.apk
   ```
   (In the editor you can instead fill in Keystore > Release in the Android
   export preset.) The script verifies the signature with `apksigner` when it
   is on your PATH.
3. Bump `version/code` and `version/name` in `export_presets.cfg` for each
   new release. For Google Play, enable *Use Gradle Build* in the preset and
   set *Export Format* to AAB.

### Regenerating assets

```
python3 tools/gen_art.py      # needs Pillow
python3 tools/gen_audio.py    # needs numpy and oggenc (vorbis-tools)
python3 tools/gen_levels.py
```

## Testing

```
python3 tools/validate_levels.py                 # all levels completable
godot --fixed-fps 60 -- --test                   # full in-engine test suite
godot --fixed-fps 60 -- --test --only=menus      # controls, mechanics, menus
godot --fixed-fps 60 -- --test --only=1_1,4_2    # specific levels
godot --fixed-fps 60 -- --test --shots=/tmp/s    # also save screenshots
```

* `validate_levels.py` simulates the player's real movement physics frame by
  frame and searches every standing position. It reports whether each
  level's goal (or boss arena) and every secret star can be reached.
* The in-engine suite checks simultaneous multi-touch input, sliding
  between buttons, jump height, no double jumps, stomp vs side damage,
  checkpoint respawn, losing a life, save/load, pause, resume and auto-pause
  on focus loss, wind, water and the air meter, quicksand, ice, crumbling and
  moving platforms. It then loads all 40 levels, sweeps the player through
  each, fights every boss to defeat, finishes the level and opens every menu.
